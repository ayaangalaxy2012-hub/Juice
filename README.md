## AI coding agent — right in your browser.

---

Point Juice at any project folder, tell it what to do, and it autonomously handles coding tasks.

---

## Getting started

- **Python 3.13+**
- An API key from OpenRouter or Google AI Studio

### 1. Install & Run
```bash
git clone https://github.com
cd juice
pip install flask requests beautifulsoup4
python3 juice.py
```

### 2. Open your browser
Go to **http://localhost:5000** to start your session.
